# Differentiable Exact X-ray Gaussian Rasterization

Used as the rasterization engine for the paper "Exact-GS: Mathematically Rigorous and Accurate 3D Gaussian Splatting for 3D X-ray Reconstruction". The repository is adapted from [diff-gaussian-rasterization](https://github.com/graphdeco-inria/diff-gaussian-rasterization), [r2_gaussian](https://github.com/Ruyi-Zha/r2_gaussian/tree/main) and [Speedy-Splat](https://github.com/j-alex-hanson/speedy-splat). .
